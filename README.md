## Redline Rush

A roguelike traffic-weaving racer on an endless 4-lane highway.

- `game.html`: the game page (published as a Claude artifact).
- `android/www/index.html`: the same game as a standalone page.
- `android/`: Capacitor project that wraps the game as an Android app. See `android/README.md` for how to build an APK.

### Controls
- Accelerator pedal (bottom right) and brake pedal (bottom left).
- Swipe left or right anywhere on the screen to steer.
- On desktop: arrow keys or WASD, P to pause.
